ImportError: cannot import name 'flash_attn_unpadded_func' (or FlashMHA, flash_attn_varlen_func, any name) from 'flash_attn...': which flash-attn releases have it

flash-attn 2.0 (2023-07-24 for 2.0.1, the first 2.x release on PyPI) renamed flash_attn_unpadded_func, flash_attn_unpadded_kvpacked_func and flash_attn_unpadded_qkvpacked_func to flash_attn_varlen_func, flash_attn_varlen_kvpacked_func and flash_attn_varlen_qkvpacked_func, and removed flash_attn.flash_attention (FlashAttention, FlashMHA); 1.0.9 is the last release with the old names. The first seven arguments are the same, so renaming the import is usually the whole fix; only deterministic is missing in 2.0 to 2.3. The opposite error, from flash_attn import flash_attn_func failing, means a 1.x install. For any other name, in any module of flash-attn, paste the error below.

How do I read the error?

  • "cannot import name" is a version mismatch between the code and flash-attn; this page answers it.
  • "undefined symbol" in flash_attn_2_cuda is a different problem: the compiled extension was built for another PyTorch or CUDA. Reinstall flash-attn against the PyTorch you have (or use a prebuilt wheel that names your PyTorch and CUDA versions).
  • From 2.7.3 the extension module is imported as flash_attn_gpu inside flash_attn_interface (it was flash_attn_cuda); code that imported that internal name breaks there.

Questions

How do I fix "cannot import name 'flash_attn_unpadded_func' from 'flash_attn.flash_attn_interface'"?

flash-attn 2.0 renamed it to flash_attn_varlen_func (and the kvpacked and qkvpacked variants the same way); 1.0.9 is the last 1.x release with the old names. Change the import, or pin pip install "flash-attn<2.0" for code you cannot change. The first seven arguments are the same; 2.0 to 2.3 have no deterministic argument (the 2.4 series has it again).

Where did FlashMHA and flash_attn.flash_attention go?

flash-attn 2.0 removed the flash_attn.flash_attention module with FlashAttention and FlashMHA. flash_attn.modules.mha.MHA is the module that remains, or call flash_attn_func directly.

Why does "from flash_attn import flash_attn_func" fail?

The installed flash-attn is 1.x, which did not export it at the top level (the first release read that does is 2.0.1). If the error is an undefined symbol in flash_attn_2_cuda instead, the build does not match your PyTorch; that is not an import-name problem and reinstalling flash-attn against your PyTorch fixes it.

Yes: every module of flash-attn from 0.2.1 to 2.8.3, 1,652 module-and-name pairs in 91 modules.

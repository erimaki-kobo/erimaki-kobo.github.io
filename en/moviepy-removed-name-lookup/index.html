AttributeError: 'VideoFileClip' object has no attribute 'subclip' (or 'set_duration', 'resize', 'fx', 'volumex'), No module named 'moviepy.editor': every name MoviePy 2 changed and what to write instead

MoviePy 2.0.0 (2024-11-20) removed moviepy.editor and renamed the clip methods. Write from moviepy import VideoFileClip; subclip is subclipped, the set_x methods are with_x (with_duration, with_position, with_audio), resize / crop / rotate are resized / cropped / rotated, volumex is with_volume_scaled, and clip.fx(vfx.fadein, 1) is clip.with_effects([vfx.FadeIn(1)]). Or keep the old names with pip install "moviepy<2". Many tutorials still show 1.x code: paste the error or the code below.

Published 2026-11-26 · MoviePy 1.0.0 to 2.2.1 installed (10 releases) · 39 of the 53 removed clip members gave the same result under their 2.x name · how

# MoviePy 1.x
from moviepy.editor import *
clip = VideoFileClip("in.mp4").subclip(5, 10)
clip = clip.resize(0.5).set_fps(24)
clip = clip.fx(vfx.fadein, 1).volumex(0.8)
txt = TextClip("Hi", fontsize=40, color="white")
txt = txt.set_position("center").set_duration(5)
CompositeVideoClip([clip, txt]).write_videofile("out.mp4")
# MoviePy 2.x
from moviepy import *
clip = VideoFileClip("in.mp4").subclipped(5, 10)
clip = clip.resized(0.5).with_fps(24)
clip = clip.with_effects([vfx.FadeIn(1)]).with_volume_scaled(0.8)
txt = TextClip(text="Hi", font="DejaVuSans.ttf", font_size=40, color="white")
txt = txt.with_position("center").with_duration(5)
CompositeVideoClip([clip, txt]).write_videofile("out.mp4")

How was this measured?

MoviePy 1.0.0, 1.0.1, 1.0.2, 1.0.3, 2.0.0, 2.1.0, 2.1.1, 2.1.2, 2.2.0, 2.2.1 were each installed from PyPI in their own environment (Python 3.11.18), and a probe listed every module file, the names of each importable module, and the members and parameters of every class, after import moviepy.editor where it exists (that import is what attaches resize, fadein and the other effect methods to the clips in 1.x). Members set in __init__ were read from real objects: a ColorClip, ImageClip, AudioClip, CompositeVideoClip, and a VideoFileClip and AudioFileClip of a one-second file written with the bundled ffmpeg.

Each rename was then run: the 1.x spelling in 1.0.3 and the 2.x spelling in 2.2.1 on the same two-second 64x48 clip (a moving gradient with a 440 Hz tone), comparing duration, size, fps, the frame at t=0.5, the mask frame and the loudest audio sample. Rows that did not come out identical say so. 1.x TextClip needs ImageMagick and could not be built here, so TextClip was run in 2.x only. 2.0.0.dev1 and dev2 (2020) were not installed.

Questions

How do I fix "'VideoFileClip' object has no attribute 'subclip'"?

MoviePy 2.0.0 (2024-11-20) renamed it: write clip.subclipped(start, end). The other methods changed the same way: set_duration, set_start, set_position and the rest are with_duration, with_start, with_position; resize, crop and rotate are resized, cropped and rotated. Run on a test clip, subclip(0.5, 1.5) in 1.0.3 and subclipped(0.5, 1.5) in 2.2.1 gave the same frames. To keep the old names: pip install "moviepy<2".

How do I fix "No module named 'moviepy.editor'"?

MoviePy 2.0.0 removed moviepy.editor. Write from moviepy import VideoFileClip, AudioFileClip, concatenate_videoclips (or from moviepy import *). Code written for 1.x then needs the renamed methods too, or pip install "moviepy==1.0.3".

How do I fix "'VideoFileClip' object has no attribute 'resize'" (or 'fx', 'fadein', 'volumex')?

In 1.x these were effect functions attached to the clip. In 2.x: clip.resized(0.5), clip.cropped(...), clip.rotated(angle, expand=True), clip.with_volume_scaled(0.5), clip.with_speed_scaled(2); and for every effect, clip.with_effects([vfx.FadeIn(1), vfx.MirrorX()]) with the effect classes from moviepy import vfx, afx. clip.fx(vfx.mirror_x) becomes clip.with_effects([vfx.MirrorX()]).

How do I fix "TextClip got an unexpected keyword argument 'fontsize'" or "multiple values for argument 'font'"?

In 2.x the first parameter of TextClip is font, a path to a font file, and the others were renamed: TextClip(text="hi", font="/path/DejaVuSans.ttf", font_size=20, color="white") ran in 2.2.1. txt is text and fontsize is font_size. TextClip("hi", font=...) raises "multiple values for argument 'font'" because "hi" lands on font.

How do I fix "write_videofile() got an unexpected keyword argument 'verbose'"?

2.x dropped verbose (and rewrite_audio) from write_videofile, and verbose from write_audiofile and write_gif. Remove the argument; logger=None silences the progress bar.

How do I fix "'ImageDraw' object has no attribute '_multiline_spacing'" in TextClip?

That is MoviePy 2.2.0 with Pillow 11.3.0: building a TextClip raised it here. 2.2.1, installed with the same Pillow, builds the same clip. pip install -U moviepy.

Why does moviepy.__version__ show the wrong version?

The attribute was not updated in three releases: 2.1.2 reports 2.1.1, and 2.2.0 and 2.2.1 report 2.1.2. Use pip show moviepy, or importlib.metadata.version("moviepy").

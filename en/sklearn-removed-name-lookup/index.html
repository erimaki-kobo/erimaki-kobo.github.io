ImportError: cannot import name 'load_boston' (or 'plot_confusion_matrix', 'joblib', any name) from 'sklearn...': which scikit-learn removed it and what to use

scikit-learn 1.2.0 (2022-12-08) removed sklearn.datasets.load_boston and sklearn.metrics.plot_confusion_matrix (use ConfusionMatrixDisplay.from_estimator); 0.24.0 (2020-12-22) removed 121 modules such as sklearn.ensemble.forest and sklearn.tree.tree, which is why old pickles fail with "No module named"; 0.23.0 removed sklearn.externals.joblib (import joblib); 0.20.0 removed sklearn.cross_validation (sklearn.model_selection). If the error comes from a library you did not write, upgrade the library or pin scikit-learn below the release that removed the name. Paste the error below for the release-by-release answer.

How was this measured?

Each of 14 scikit-learn releases (the first of every minor from 0.22, plus the latest) was installed from PyPI in its own environment, the public names, __all__ and submodules of sklearn and 45 of its modules were listed, and getattr (or import, for a submodule) was run for the union of all names in every release. A name counts when it is in the module's __all__, or is a submodule, so names a file merely imported are left out. The replacement text is read from the installed source of the last release that had the name (its deprecation decorator or warnings.warn string, or the warning given on import). Removals before 0.22 (no Python 3.8 wheels) were read from the source at the 0.19.2, 0.20.0, 0.21.3 and 0.22 tags.

Patch releases were not read: a name removed in x.y.1 shows at the next minor.

Questions

How do I fix "cannot import name 'load_boston' from 'sklearn.datasets'"?

scikit-learn 1.2.0 (2022-12-08) removed load_boston; 1.0 and 1.1 warned that the dataset has an ethical problem. The warning suggests fetch_california_housing() or the Ames housing data (fetch_openml(name="house_prices", as_frame=True)), and shows how to read the original file from lib.stat.cmu.edu if you must reproduce old work. Or pin scikit-learn<1.2.

How do I fix "cannot import name 'plot_confusion_matrix' from 'sklearn.metrics'"?

scikit-learn 1.2.0 removed plot_confusion_matrix, plot_roc_curve, plot_precision_recall_curve and plot_det_curve (and inspection.plot_partial_dependence). Use the display classes: ConfusionMatrixDisplay.from_estimator(clf, X, y) or .from_predictions(y_true, y_pred), RocCurveDisplay.from_estimator, PrecisionRecallDisplay, DetCurveDisplay, PartialDependenceDisplay.

How do I fix "No module named 'sklearn.ensemble.forest'" when loading a pickle?

The pickle was written by scikit-learn 0.23 or earlier, which had public modules such as sklearn.ensemble.forest, sklearn.tree.tree and sklearn.linear_model.logistic; 0.24.0 (2020-12-22) removed 121 of them (0.22 and 0.23 warned). Load the file in an environment with the same scikit-learn version that wrote it (pip install "scikit-learn<0.24"), and save the model again from there in a format you can rebuild, or retrain it. In code, import from the package: from sklearn.ensemble import RandomForestClassifier.

How do I fix "cannot import name 'joblib' from 'sklearn.externals'"?

scikit-learn 0.23.0 (2020-05-12) removed the vendored copy. pip install joblib, then import joblib (joblib.dump, joblib.load). Old pickles that refer to sklearn.externals.joblib need scikit-learn<0.23 to load.

How do I fix "No module named 'sklearn.cross_validation'"?

scikit-learn 0.20.0 (2018-09-26) removed sklearn.cross_validation, grid_search and learning_curve; their contents are in sklearn.model_selection (train_test_split, KFold, GridSearchCV, learning_curve).

AttributeError: module 'PIL.Image' has no attribute 'ANTIALIAS' (or 'ImageDraw' object has no attribute 'textsize', 'getsize', any name): which Pillow removed it and what to use

Pillow 10.0.0 (2023-07-01) removed Image.ANTIALIAS (use Image.LANCZOS), Image.LINEAR and Image.CUBIC (BILINEAR, BICUBIC), ImageDraw.textsize (use textbbox or textlength) and font.getsize (use getbbox or getlength); 9.1 to 9.5 warned. Pillow 12.0.0 removed ImageMath.eval (use lambda_eval or unsafe_eval). If the error comes from a library you did not write, upgrade the library or pin Pillow below the release that removed the name. How was this measured?

Each of 28 Pillow releases (every minor from 7.0.0, plus the latest) was installed from PyPI in its own environment, the public names of the PIL modules and of the Image, ImageDraw, FreeTypeFont and ImageFont classes were listed with dir(), and getattr was run for the union of all names in every release. Releases: 7.0.0 (Python 3.8), 7.1.0 (Python 3.8), 7.2.0 (Python 3.8), 8.0.0 (Python 3.8), 8.1.0 (Python 3.8), 8.2.0 (Python 3.8), 8.3.0 (Python 3.8), 8.4.0 (Python 3.8), 9.0.0 (Python 3.8), 9.1.0 (Python 3.8), 9.2.0 (Python 3.8), 9.3.0 (Python 3.8), 9.4.0 (Python 3.8), 9.5.0 (Python 3.8), 10.0.0 (Python 3.8), 10.1.0 (Python 3.8), 10.2.0 (Python 3.8), 10.3.0 (Python 3.8), 10.4.0 (Python 3.8), 11.0.0 (Python 3.9), 11.1.0 (Python 3.9), 11.2.1 (Python 3.9), 11.3.0 (Python 3.9), 12.0.0 (Python 3.12), 12.1.0 (Python 3.12), 12.2.0 (Python 3.12), 12.3.0 (Python 3.13), 13.0.0 (Python 3.13). Pillow's modules have no __all__, so the table keeps class members and the names Pillow itself deprecated (a warning on access, or a deprecate() call or warning in the definition); helpers a module merely imported are left out, but the lookup still answers for them. The text is read from the installed source of the last release that had the name; Pillow's deprecate("textsize", 10, "textbbox or textlength") calls are turned into the sentence its helper prints. ImageTk, ImageQt and ImageGrab were not read (their import depends on tkinter, Qt or a display).

Patch releases were not read: a name removed in x.y.1 shows at the next minor.

Questions

How do I fix "module 'PIL.Image' has no attribute 'ANTIALIAS'"?

Pillow 10.0.0 (2023-07-01) removed Image.ANTIALIAS; 9.1 to 9.5 warned. Use Image.LANCZOS (the same filter), or Image.Resampling.LANCZOS, which exists from 9.1.0: img.resize((w, h), Image.LANCZOS). The same release removed Image.LINEAR (use BILINEAR) and Image.CUBIC (use BICUBIC). If the error comes from a library, upgrade it, or pin pillow<10.

How do I fix "'ImageDraw' object has no attribute 'textsize'"?

Pillow 10.0.0 removed ImageDraw.textsize and multiline_textsize. Use draw.textbbox((0, 0), text, font=font), which returns (left, top, right, bottom): width = right - left, height = bottom - top; or draw.textlength(text, font=font) for the width alone.

How do I fix "'FreeTypeFont' object has no attribute 'getsize'"?

Pillow 10.0.0 removed font.getsize, getsize_multiline and getoffset. Use font.getbbox(text) (left, top, right, bottom) or font.getlength(text) for the advance width.

How do I fix "module 'PIL.ImageMath' has no attribute 'eval'"?

Pillow 12.0.0 (2025-10-15) removed ImageMath.eval. Use ImageMath.lambda_eval with a function, or ImageMath.unsafe_eval for a string expression you trust (it runs Python code).

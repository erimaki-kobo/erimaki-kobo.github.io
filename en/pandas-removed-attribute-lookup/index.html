AttributeError: 'DataFrame' object has no attribute 'append' (or 'iteritems', 'ix', 'applymap', any name): which pandas removed it and what to use

pandas 2.0.0 (2023-04-03) removed DataFrame.append and Series.append (use pd.concat), iteritems (use items), Int64Index and Float64Index (use pd.Index) and 43 more; pandas 3.0.0 (2026-01-21) removed DataFrame.applymap (use DataFrame.map) and 42 more; pandas 1.0.0 removed .ix (use .loc or .iloc) and 76 more. For 163 of the 170 the last release that had the name gives a deprecation text, quoted in the table. How was this measured?

Each of 14 pandas releases (the first of every minor from 0.25.3, plus the latest) was installed from PyPI in its own environment, the public names of each object were listed with dir(), and getattr was run for the union of all names in every release. Releases: 0.25.3 (Python 3.8, NumPy 1.19.5), 1.0.0 (Python 3.8, NumPy 1.19.5), 1.1.0 (Python 3.8, NumPy 1.19.5), 1.2.0 (Python 3.9, NumPy 1.19.5), 1.3.0 (Python 3.9, NumPy 1.21.6), 1.4.0 (Python 3.10, NumPy 1.22.4), 1.5.0 (Python 3.10, NumPy 1.23.5), 2.0.0 (Python 3.11, NumPy 1.24.4), 2.1.0 (Python 3.11, NumPy 1.26.4), 2.2.0 (Python 3.12, NumPy 1.26.4), 2.3.0 (Python 3.12, NumPy 2.2.6), 3.0.0 (Python 3.12, NumPy 2.5.5), 3.1.0 (Python 3.12, NumPy 2.5.5), 3.1.1 (Python 3.12, NumPy 2.5.5). A name is "removed" when getattr on the class (or the module) raises in a release after one where it worked. The replacement text is the string the name's own code passed to warnings.warn in the last release that had it, read from the installed source with inspect and ast (or, for module attributes, the warning given on access); where the code had none, a warning elsewhere in pandas that names it, or our note.

Patch releases were not read: a name removed in x.y.1 shows at the next minor. Series.flags went in 1.0.0 and came back in 1.2.0 with a different meaning.

Questions

How do I fix "'DataFrame' object has no attribute 'append'"?

pandas 2.0.0 (2023-04-03) removed DataFrame.append and Series.append; 1.4 and 1.5 warned. Collect the pieces and call pd.concat once: pd.concat([df, new_rows], ignore_index=True), where new_rows is a DataFrame (pd.DataFrame([row_dict]) for one row). Or pin pandas<2 (1.5.3 is the last 1.x).

How do I fix "'DataFrame' object has no attribute 'iteritems'"?

pandas 2.0.0 removed iteritems; use items(), which yields the same (column name, Series) pairs. Older libraries that call iteritems need upgrading, or pandas<2.

How do I fix "'DataFrame' object has no attribute 'applymap'"?

pandas 3.0.0 (2026-01-21) removed DataFrame.applymap; it was renamed DataFrame.map in 2.1.0, and 2.1 to 2.3 warned. Use df.map(func).

How do I fix "'DataFrame' object has no attribute 'ix'"?

pandas 1.0.0 (2020-01-30) removed .ix. Use .loc for labels and .iloc for positions.

How do I fix "module 'pandas' has no attribute 'Int64Index'"?

pandas 2.0.0 removed Int64Index, UInt64Index and Float64Index. Use pd.Index with a dtype, for example pd.Index([1, 2], dtype='int64'). The same release removed pd.np (import numpy) and pd.datetime (import datetime).
